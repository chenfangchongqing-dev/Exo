Conversation orale · Test pédagogique et WebRTC

Écho · Accompagnement métacognitif

Choisissez un mode et un niveau, puis essayez de parler naturellement avec Écho. Les consignes métacognitives sont transmises au modèle vocal au début de chaque séance. Durée maximale : 90 secondes.

Ce qu’Écho doit faire

Écouter avant de guider, laisser l’apprenant développer son propos, proposer un étayage adapté lorsqu’une difficulté apparaît, et accompagner un bilan réflexif si l’apprenant le souhaite.

En mode libre, aucun sujet n’est nécessaire. Écho peut engager la conversation et s’adapter à vos réponses.

Adresse de la fonction echo-realtime (région Pékin). Modifiez-la uniquement si l’adresse indiquée dans votre console est différente.

Utilisez votre code de test, jamais la clé API de Bailian. Le code n’est pas conservé dans le navigateur.

Temps maximum par essai : 01:30

Idées pour tester les stratégies pédagogiques

Conversation libre : « Salut, je veux seulement discuter, je n’ai pas de sujet. » Écho doit engager une conversation naturelle, sans exiger de tâche.

Conversation guidée : choisissez « L’uniforme à l’école », puis dites « Je n’ai pas d’idée ». Écho doit proposer des pistes, plutôt que réclamer un texte.

Difficulté lexicale : « Je n’arrive pas à trouver le mot. » Écho doit offrir une aide brève, puis vous redonner la parole.

Retour réflexif : avant de terminer, dites « Écho, faisons un petit bilan ». Écho doit commencer par votre propre appréciation, puis proposer un retour concret sans note.

Protection : l’enregistrement ne reste pas sur cette page. Lors d’un essai réussi, le microphone transmet votre voix au service de modèle externe via WebRTC. Le modèle peut consommer des jetons gratuits pendant la session. Les instructions pédagogiques de ce test sont visibles dans le code du navigateur et ne constituent pas encore une configuration sécurisée pour les étudiants. Ne communiquez pas ce lien ni le code avant validation de la sécurité et des plafonds d’usage.
