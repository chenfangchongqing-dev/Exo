# Exo · 个人账号登录系统（试运行部署说明）

状态：代码已提交 GitHub；Cloudflare Pages 的 D1 绑定、第一次教师账号初始化及正式切换需在 Cloudflare 项目中完成。**目前用户网站仍使用原访问方式**；不得仅凭仓库提交就宣称已经开通一人一号。

## 设计范围

- 首页继续公开。Café de Flore 和其他学习板块在正式启用后均需要每个人自己的账号密码。
- 教师拥有单独管理员账号，可批量发放学生的 **一次性初始密码**、重置临时密码；学生首次登录时必须改为自己的密码。
- 学生可自行选 **女生（蓝色笔记本／围巾）** 或 **男生（蓝色笔记本／蓝外套）** 两种探索形象。形象是偏好选项，不代表性别识别。
- 教师专用页面仍限制教师身份；教师栏目下的 Café de Flore 例外，学生登录后也能进入。
- 学生身份 ID 只在服务器数据库中记录；密码使用 PBKDF2-SHA256（随机盐、260,000 次迭代），**不保存明文密码**。
- 8 小时服务端可撤销的 HttpOnly + Secure + SameSite=Lax 登录会话；失败登录锁定、同源表单校验。
- 目前 Café de Flore 护照积分仍在 localStorage，仅供演示；正式跨设备保存、兑换账本需开发独立的服务端奖励接口，不能把浏览器的 XP 当成兑换余额。

## Cloudflare 启用顺序（管理员操作）

1. 进入 Cloudflare 控制台，创建 D1 数据库，例如 `exo-identity`。
2. 为 **exo-fr** Pages 项目的 Functions 添加 D1 绑定：**变量名固定为 `EXO_DB`**，绑定新数据库。注意 Preview/Production 环境是否分别配置。
3. 将仓库的 `db/migrations/0001_exo_identity.sql` 应用到 D1 数据库。在控制台 SQL Console 执行，或在本地配置好 Wrangler 后执行：

   `npx wrangler d1 execute exo-identity --remote --file=db/migrations/0001_exo_identity.sql`

4. Pages 环境变量配置 `EXO_AUTH_MODE=pilot`，并创建长度至少 32 个不可预测字符的 **加密 Secret** `EXO_BOOTSTRAP_SECRET`。该值不写在 GitHub、网页或聊天记录中。
5. 重新部署后，访问 `https://exo-fr.pages.dev/_account/setup`，亲自输入初始化密钥，创建首个教师个人账号。
6. **立即删除 `EXO_BOOTSTRAP_SECRET`**（并重新部署）。访问 `/_account` 登录，再在 `/_account/admin` 批量创建学生账号。创建结果只显示一次，分别私发学生。建议先创建 2 个测试学生进行端到端检查。
7. Pilot 阶段原有公开首页和共享密码功能继续运行，可在 `/_account` 测试个性化登录、登出、改密、管理和形象选择。
8. 试点验证后再设置 **`EXO_AUTH_MODE=individual`** 重新部署。切换后 `/_class-access` 通用密码不再用于板块访问；首页仍公开，教师区只允许教师账号，Café de Flore 和其他学生板块要求个人登录。
9. 用无痕窗口检查登录状态、学生误入教师区、首次改密、锁定提示、登出后再访问和手机浏览器表现。需要回滚可将模式改回 `pilot`，此前通用访问码 Secret 应保留到迁移验证完成。

## 建议验收用例

| 测试 | 预期 |
|---|---|
| 学生 A 登录 | 只能进入学生页面和个人空间 |
| 学生 B 登录 | 与 A 不共用会话和密码 |
| 首次登录 | 必须修改临时密码 |
| 失败登录 5 次 | 暂时锁定账户 15 分钟 |
| 学生直接打开 /Events/ | 403，不进入教师资源 |
| 学生直接打开 /Events/au-cafe-de-flore/ | 登录后允许进入 |
| 未登录打开任意课程模块 | 重定向到 /_account 并保留返回地址 |
| 未登录打开首页 | 正常显示首页和双人物游戏入口 |
| 教师批量创建学生账号 | 每人不同随机密码、仅一次展示 |
| 退出登录 | 服务器删除当前会话 |

## 上线边界与后续

这份实现提供单个课程/学院内部试点的账号基础。未来正式用于大量用户时，仍应进一步配置 Cloudflare WAF/速率限制、账号恢复流程、审计记录、教学数据保留期限、后台账号停用和密码泄露应急预案。

为避免老师误以为学生已完成在线学习，当前形象偏好只保存于个人账号；现有匿名化作业、Idée 和 Écho 及护照等模块暂未接入个人学习事件账本。下一阶段应先验证身份、再逐个绑定学习数据与奖励事件。
